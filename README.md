# MotoLean site

Landing page for MotoLean: Corner Coach, the lean angle meter and voice corner coach for iPhone.

Static HTML, served by GitHub Pages from `main`. Sources of truth for the copy and the screenshots live in the app repository (`AppStore/site`).

Support and privacy policy: https://muilton.github.io/motolean-legal/
